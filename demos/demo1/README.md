# Lipids & Liver — Demo 1 (Versión Estática Local Sin Servidor)

Esta carpeta contiene la **compilación completa de la web oficial de Astro (`/dist`)**, adaptada especialmente con **rutas 100% relativas y enlaces a archivos estáticos**.

### Características de esta versión:
1. **Sin servidor web**: No hace falta ejecutar `npm run dev`, `node`, `astro preview` ni ningún servidor local.
2. **Navegación local directa (`file://`)**: Puedes hacer doble clic en `index.html` (o en cualquier subpágina) desde el explorador de archivos y la web cargará todas las imágenes, estilos CSS, fuentes, scripts interactivos, modales y enlaces entre páginas de forma correcta.
3. **Selectores dinámicos adaptados**: Los menús desplegables de cambio de investigador (`/curriculum`), tesis (`/tesis`) y líneas (`/lineas`) navegan de forma fluida usando rutas relativas directas a cada archivo `index.html`.
4. **Soporte multilingüe completo**: Las versiones en español (`/index.html`), euskera (`/eu/index.html`) e inglés (`/en/index.html`) están enlazadas y operativas sin requerir configuración de servidor.
